# 🧘 Daily Yoga AI Agent (Free & Cross-Platform)

An open-source, **100% free AI Yoga & Mobility Coach** that creates safe, step-by-step Yoga routines with pose illustrations tailored for **any age** (Kids, Teens, Adults, Seniors, and Chair-Assisted Care).

Designed so **non-technical users** can download and run it in a browser with **zero coding and zero terminal setup**.

## ✨ Features
- **Age-Tailored Routines:** Customized guidance for Kids (5–12), Teens, Adults, Seniors (56–75), and Gentle Care (75+).
- **Visual Pose Guides:** AI-generated posture illustrations with automatic vector diagram fallbacks.
- **Built-In Pose Timers & Chimes:** Practice hands-free with per-pose countdown timers.
- **Senior-Friendly Accessibility:** One-click `A+ / A-` text scaling, Chair Yoga mode, and Print/PDF export.
- **$0 Cost Out of the Box:** Works immediately with no credit card or mandatory signup (optional free Google Gemini API key supported).

## 🚀 How to Download & Run (No Coding Required)

1. Click the green **`<> Code`** button at the top of this page and select **`Download ZIP`**.
2. Extract (unzip) the downloaded folder anywhere on your computer.
3. Double-click the launcher for your system:
   - **Windows:** Double-click `Start-Yoga-Agent-Windows.bat`
   - **Mac:** Double-click `Start-Yoga-Agent-Mac.command` *(if macOS asks for permission the first time, right-click → **Open**)*
   - **Linux:** Run `./start-yoga-agent-linux.sh`
4. Your web browser will automatically open the Yoga Coach app!
